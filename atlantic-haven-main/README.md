# Atlantic Haven Hotels — Hackathon Machine Learning M1

Ce dépôt contient le sujet et les ressources de l’examen final **Machine Learning & Data Science — M1** organisé à l’[ISPM Madagascar](https://www.ispm-edu.com).

L’objectif du projet est de construire un modèle capable de prédire l’annulation d’une réservation hôtelière à partir d’un dataset entièrement synthétique couvrant dix régions italiennes.

## Consulter le sujet

Le sujet est disponible en deux formats :

- 🌐 **[Version web interactive](./sujet.html)**
- 📄 **[Version PDF](./sujet.pdf)**

Durée du hackathon : **8 heures, de 08h00 à 16h00**.

## Contenu du dépôt

```text
.
├── README.md
├── sujet.html
├── sujet.pdf
└── ressources/
    ├── reservations_train.csv
    ├── reservations_test.csv
    ├── sample_submission.csv
    ├── data_dictionary.csv
    └── readme-model.md
```

- `reservations_train.csv` : 8 000 réservations avec la variable cible ;
- `reservations_test.csv` : 2 000 réservations plus récentes, sans la cible ;
- `sample_submission.csv` : format attendu du fichier de prédictions ;
- `data_dictionary.csv` : description des variables ;
- `readme-model.md` : canevas du rapport à compléter par chaque équipe.

## Démarrage rapide

1. Clonez ou téléchargez ce dépôt.
2. Consultez la [version web](./sujet.html) ou téléchargez la [version PDF](./sujet.pdf).
3. Consultez les fichiers du dossier [`ressources`](./ressources/).
4. Créez votre propre dépôt de travail et respectez les livrables précisés dans le sujet.

## Avertissement

Toutes les données sont **synthétiques** et destinées exclusivement à un usage pédagogique. Les particularités régionales représentent des contextes touristiques, saisonniers et opérationnels ; elles ne décrivent pas les comportements réels des populations.
